Spade — Product Test & Score Guide

Walk every user-facing flow, score each as Pass / Partial / Fail, and jot notes. Your scores + notes are saved in this browser (localStorage) and the scoreboard updates live. Use Export results to copy a markdown report.

Setup before you start. From the repo root run make dev (starts the API on :8765 and the Next UI on :3000) — or run them separately: make api and cd apps/client && npm run dev. Open http://127.0.0.1:3000. Two seeded projects help: Hello Spade (PoC) is populated (tasks, brain, a connected account) — use it for the data-rich flows; create a fresh empty project to test empty/blank-slate states.
