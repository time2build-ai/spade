Why it fits Spade

  • Floats over any view — ask while reading the graph, backlog, or a task
  • Draggable + collapsible = stays out of the way, always one key away
  • Glass + lavender aura is a natural brand extension
  • Quick-actions ("backlog", "decisions", "recap") map to real Spade reads

Watch-outs

  • Floating window state to manage (position, collapsed, persistence)
  • Can occlude content — needs a remembered position + easy hide
  • Mobile/narrow needs a fallback (snap to full-width)
How I'd build it: replace the right AskDock with a floating .float container (handle pill + glass card), remembered position in localStorage, default top-center, ⌘K spring-in, Hide collapses to the pill, drag via the handle.
