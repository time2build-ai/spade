# Spade MVP — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Build the Spade MVP core loop on the existing foundation: a PM **Task** → grounded by the **Product Brain** → executed by a 4-stage agent **Pipeline** (Developer→Reviewer→Integrator→Documentor) on the project's account pool → shipped, with Backlog/Brain/Pipelines/Home views.

**Architecture:** New domain modules (`tasks.py`, `brain.py`, `pipelines.py`) over `db.py` helpers (plain-dict returns, db-helpers-only — mirror `accounts.py`/`projects.py`). New `spade_server.py` FastAPI router included like `registry_server`. Pipeline stages spawn via the foundation's `server._spawn_agent(... parent=None, cwd=project path, report_context=prev report)`; auto-advance via an additive parentless-`done` collector branch in the poll loop. Frontend extends the existing vanilla-JS `/ui` app.

**Tech Stack:** Python 3, stdlib sqlite3, FastAPI, pytest, vanilla JS.

**Reference:** Spec `docs/superpowers/specs/2026-06-15-spade-mvp-design.md` (read it — it has the full data model + wiring). Foundation modules: `db.py` (`query/execute/tx`), `projects.py`, `accounts.py`, `server.py` (`_spawn_agent`, `_poll_loop`, `_info`, `registry_server` include pattern), `roles_seed.py`. Design handoff views for UI cues: `~/downloads/design_handoff_spade/views/{backlog,brain,orchestrator,task,home}.jsx`.

**Conventions:** Tests `tests/test_<module>.py`, plain pytest, autouse `tui_pilot_home` fixture gives a fresh temp DB. Run one: `.venv/bin/python -m pytest tests/test_tasks.py -v`. Run all: `.venv/bin/python -m pytest -q`. New schema tables are appended to `tui_pilot/schema.sql` (CREATE TABLE IF NOT EXISTS — runs on every connect, so additive on existing DBs).

### Task 3.2: pipelines.py state machine (spawn injected)
- [ ] **Step 1: failing test** — `tests/test_pipelines.py`:
```python
from tui_pilot import pipelines, tasks, projects
def _setup():
    projects.create(id="acme", name="Acme", path="/w")
    return tasks.create(project_id="acme", title="Build X")["id"]

def test_create_run_builds_four_ordered_stages():
    tid = _setup()
    run = pipelines.create_run(project_id="acme", task_id=tid)
    stages = pipelines.get(run["id"])["stages"]
    assert [s["role"] for s in stages] == ["developer","reviewer","integrator","documentor"]
    assert all(s["state"] == "queued" for s in stages)

def test_advance_runs_stages_then_ships():
    tid = _setup()
    run = pipelines.create_run(project_id="acme", task_id=tid)
    spawned = []
    def fake_spawn(stage_idx, report):  # injected; returns (session_id, account_id)
        spawned.append((stage_idx, report)); return (f"sess{stage_idx}", "acct")
    # start stage 0
    pipelines.start_stage(run["id"], 0, fake_spawn)
    assert pipelines.get(run["id"])["stages"][0]["state"] == "running"
    # complete 0 -> auto-start 1 ... through 3 -> ship
    for i in range(4):
        pipelines.complete_stage(run["id"], i, report=f"r{i}", spawn=fake_spawn)
    run2 = pipelines.get(run["id"])
    assert run2["status"] == "shipped"
    assert tasks.get(tid)["status"] == "shipped"
    assert [s["state"] for s in run2["stages"]] == ["done","done","done","done"]
```
- [ ] **Step 2-4:** Implement `pipelines.py`:
  - `STAGES = ["developer","reviewer","integrator","documentor"]`.
  - `create_run(project_id, task_id)` → insert run (status queued, current_stage 0) + 4 queued stages (role/stage_order). Return `get(run_id)`.
  - `get(run_id)` → run dict with `stages` list (ordered). `list_for_project(project_id)`.
  - `start_stage(run_id, idx, spawn)` → call `spawn(idx, report=None_or_prev)`, set stage state running + session_id/account_id, run status running.
  - `complete_stage(run_id, idx, report, spawn)` → mark stage idx done; if idx < 3: start stage idx+1 via `spawn(idx+1, report)` (state running); if idx == 3: run status='shipped', `tasks.move(task_id,'shipped')`. Advance `current_stage`. On a spawn exception: stage state 'failed', run status 'paused' (swallow+return).
  - Keep `spawn` an injected callable so this module is tmux-free/testable.
- [ ] Run → pass. Commit `git commit -am "feat(spade): pipelines state machine"`.
