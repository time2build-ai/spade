# Video de demostración

Este directorio aloja el **video de demostración (4–5 minutos)** que muestra y
explica el escenario completo de extremo a extremo descripto en el
[instructivo de puesta en marcha](../../README.md#4-escenario-completo-de-extremo-a-extremo-reproducible):
ingesta de una fuente → generación de issues con IA → ejecución de un issue por
un agente → verificación de la trazabilidad sobre el grafo de conocimiento.
