Project 1

🧠 “Nimbus AI” — client advisory ✓ NO REPO NEEDED

A consulting engagement: the client wants research and written deliverables, no code. This exercises the Research and Docs lifecycles — the fastest way to see the whole thing work end-to-end.

Create it: Projects → New → name it Nimbus AI. Leave the repository blank. Open its Backlog. Now add each use case below.

UC-1Compare vector databasesexpect 🔬 Research

General research → should fan out into parallel investigators + one synthesized report. This is the marquee use case.

Title
Research: top vector databases for RAG in 2026 and their tradeoffs
Description
Compare pgvector, Pinecone, Weaviate, Qdrant and Milvus on cost, scale, latency, hybrid search and ops burden. Recommend one for a mid-size client.
Verify: router suggests 🔬 Research → confirm → Start (no repo prompt). Approve the scope (the angle list), then watch the card show ▶ N agents running in parallel. A manager merges them into one report grouped over per-angle findings.
⚑ Scope gate⚑ Review gate
UC-2SOW for the engagementexpect 📄 Docs

"SOW" should trigger Docs and auto-pick the SOW template. Produces a shareable styled document.

Title
Write a SOW for the Nimbus AI advisory engagement
Description
Statement of work covering scope, deliverables, timeline, milestones, assumptions and pricing for a 6-week AI advisory engagement.
Verify: suggestion says 📄 Docs and names the SOW template. Approve the outline, let it draft, then open the doc — it renders styled. Open the share link (/api/doc/…) in a new tab: standalone, client-ready, no scripts.
⚑ Outline gate⚑ Review gate

UC-4Request changes at a gateany kind

Gates aren't just "approve". Test the reject → rework path so you trust the human-in-the-loop.

What to do
On UC-1's scope gate (or UC-2's outline), click "Request changes" and type a note like: add a section on hybrid search cost.
Verify: the task goes back to the agent (not forward), your note appears in the activity log, and a revised artifact comes back to the same gate. Then approve.
⚑ same gate re-opens
